# RFC-001 — Nuevas fuentes de observabilidad

## Estado

Future

## Idea

Extender Akritas más allá de Dokploy logs.

Posibles fuentes:

- OpenTelemetry traces;
- Loki;
- Grafana;
- Prometheus;
- Sentry;
- Kubernetes events;
- cloud provider logs;
- application metrics.

La combinación de logs, métricas y traces permitiría investigaciones más completas y reducir falsos diagnósticos.
