# RFC-002 — Remediación autónoma avanzada

## Estado

Future

## Idea

Permitir que Akritas avance más allá de la creación de Pull Requests.

Capacidades potenciales:

- auto-merge bajo políticas específicas;
- deploy automático;
- rollback;
- restart de servicios;
- cambio temporal de configuración;
- rate limiting;
- feature flag shutdown;
- ejecución de runbooks.

Requeriría políticas de riesgo, autorización y auditoría mucho más estrictas.
