# RFC-004 — Notificaciones y colaboración

## Estado

Future

## Idea

Agregar canales de comunicación para incidentes:

- Slack;
- Microsoft Teams;
- Discord;
- email;
- webhooks.

Akritas podría notificar cuando:

- detecta un incidente;
- termina una investigación;
- crea una Issue;
- crea una Pull Request;
- una remediación falla.
